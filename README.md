# Atlas Olfativo

Um guia digital minimalista sobre perfumaria masculina, desenvolvido para iniciantes, com foco em apresentar famílias olfativas e conceitos fundamentais através de uma estética editorial sofisticada.

## 🎯 Objetivo
Projeto de portfólio com foco em front-end, desenvolvido para demonstrar:
- Estruturação semântica
- Criação de layouts responsivos
- Tradução de identidade visual premium em código

## 🚀 Funcionalidades
- Abordagem mobile-first
- Navegação fluida entre seções
- Estrutura semântica com listas de definição (`<dl>`, `<dt>`, `<dd>`)
- Layouts editoriais com CSS Grid e Flexbox
- Uso de camadas (z-index e stacking context)
- Aplicação de efeitos visuais com `mask-image` e `filter`

## 🛠️ Tecnologias
- HTML5 (semântica)
- CSS3
  - Flexbox
  - Grid
  - Variáveis CSS
  - Positioning e efeitos visuais
